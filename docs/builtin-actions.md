# 内置动作

动作编辑器按桌面、浏览器、系统、访达、窗口操作分类，同时保留快捷键、媒体控制、打开应用、URL、Shell 和 AppleScript。

## 桌面

调度中心、应用程序窗口和左右切换空间继续使用原有系统动作，已有手势与自定义快捷键保持兼容。显示桌面读取 macOS 的快捷键设置，明确禁用时报告不可用。显示／隐藏程序坞切换 macOS 的 Dock 自动隐藏设置。

显示／隐藏桌面文件调整 Finder 的桌面显示偏好，会重启 Finder 刷新，并尽量恢复原有文件夹窗口；标签页、选中状态和特殊窗口可能无法恢复，不会删除文件。它与临时移开所有窗口的“显示桌面”不同。

## 浏览器

前进、后退、到顶、到底、新建或关闭标签页、前后切换标签页均作用于手势开始时捕获的浏览器窗口。发送快捷键前沿用已有目标激活和验证流程，不向当前任意前台应用发送关闭标签页等操作。

支持 Safari、Chrome、Edge、Firefox、Brave、Arc、Vivaldi、Opera、Orion、Zen 及部分开发版本。网页内嵌编辑器或滚动区域可能影响到顶／到底行为，自定义快捷键可继续使用原快捷键动作。

## 系统

提供关机、重启、睡眠、锁屏、屏幕保护、暗色／亮色、清倒废纸篓、保持唤醒、恢复自动睡眠与随机壁纸。关机、重启、清倒废纸篓执行前显示确认，不强制丢弃其他应用的未保存文档。

保持唤醒使用进程持有的电源断言，仅阻止空闲自动睡眠，不保证合盖后继续运行，也不强制屏幕常亮。恢复自动睡眠只释放 InMouse 自己的断言，退出应用同样自动释放，不修改系统全局睡眠配置。

随机壁纸先选择本地图片文件夹，每次从该目录的直接子文件中选图，不递归扫描隐藏文件或子目录，多张图时避开当前主屏壁纸，并应用到已连接的所有显示器。

## 访达

提供新建窗口／文件夹、上层目录、打开所选文件夹或文件、隔空投送、启动磁盘根目录、下载、应用程序、最近使用、用户目录、文稿、iCloud 云盘、网络、前往文件夹、连接服务器与将所选图片设为壁纸。

目录操作打开对应本机目录，交互式操作激活 Finder 并作用于其前台窗口。“打开所选项”要求先在 Finder 中选择文件夹或文件，设为壁纸要求只选中一张有效图片。未启用 iCloud 云盘或目录不可访问时明确报错，不创建替代目录。

## 配置兼容

包含新增内置动作的配置和导出使用 v9 格式，主动作和第二动作均纳入检测；原有动作仍保持对应的旧格式版本和原有存储形式。v9 配置需使用支持这些动作的 InMouse 版本，旧版本不应编辑或覆盖它。

开发验证覆盖配置导入导出、重载、浏览器目标路由、保持唤醒生命周期、目录扫描与脚本语法。关机、重启、清倒废纸篓等不会在自动测试中实际执行。
